အက်ပ် ၄ ခု

ဖုန်းထဲတွင် APK တပ်ဆင်နည်း လမ်းညွှန်

၁

APK ဖိုင်ကို ဒေါင်းလုဒ်လုပ်ပါ

အထက်ပါ စာရင်းမှ မိမိလိုချင်သော အက်ပ်၏ အစိမ်းရောင် "Download APK" ခလုတ်ကို နှိပ်၍ ဒေါင်းလုဒ်စတင်ပါ။

၂

ဒေါင်းလုဒ်ရယူထားသော ဖိုင်ကို ဖွင့်ပါ

ဒေါင်းလုဒ်ပြီးဆုံးပါက အသိပေးချက် (Notification) ဘားမှဖြစ်စေ၊ ဖုန်း၏ Downloads ဖိုဒါထဲမှဖြစ်စေ APK ဖိုင်ကို နှိပ်၍ဖွင့်ပါ။

၃

အမည်မသိ ရင်းမြစ်များ ခွင့်ပြုပါ (Allow Unknown Sources)

လုံခြုံရေးသတိပေးချက် ပေါ်လာပါက Settings သို့သွားပြီး "Allow from this source" (သို့မဟုတ်) "ဤရင်းမြစ်မှ သွင်းယူခွင့်ပြုရန်" ကို ဖွင့်ပေးပါ။

၄

Install ကို နှိပ်၍ အပြီးသတ်ပါ

ပေါ်လာသော အတည်ပြုချက် မျက်နှာပြင်တွင် "Install" (တပ်ဆင်မည်) ကို နှိပ်ပြီး ခေတ္တစောင့်ဆိုင်းပါက အောင်မြင်စွာ အသုံးပြုနိုင်ပါပြီ။
