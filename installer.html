Web ADB တပ်ဆင်ရေး

Google Chrome မှတစ်ဆင့် USB ဒေတာကြိုးဖြင့် Android ဖုန်းထဲသို့ APK တိုက်ရိုက်သွင်းယူပါ

WebUSB ကို ဤဘရောက်ဆာတွင် အသုံးမပြုနိုင်ပါ ဤနည်းပညာသည် Google Chrome သို့မဟုတ် Microsoft Edge ဘရောက်ဆာများတွင်သာ အလုပ်လုပ်ပါသည်။ ကျေးဇူးပြု၍ Chrome/Edge ဖြင့် ဤစာမျက်နှာကို ပြန်လည်ဖွင့်ပေးပါ။
WebUSB အသုံးပြုခွင့် ကန့်သတ်ထားပါသည် (Permissions Policy) ဤစာမျက်နှာကို Preview iFrame (ကန့်သတ်ဘောင်) အတွင်း ဖွင့်ထားပါက Browser ၏ လုံခြုံရေးမူဝါဒအရ USB ချိတ်ဆက်မှုကို ခွင့်မပြုပါ (Disallowed by permissions policy)။ ဖုန်းနှင့် တိုက်ရိုက်ချိတ်ဆက်နိုင်ရန် အောက်ပါခလုတ်ကို နှိပ်၍ သီးသန့် Browser Tab အသစ်တွင် ဖွင့်ပေးပါ- Tab အသစ်တွင် သီးသန့်ဖွင့်မည် (Open in New Tab)

အရေးကြီး သတိပေးချက်

ဤစနစ်သည် WebUSB နည်းပညာဖြင့် အလုပ်လုပ်သောကြောင့် Google Chrome သို့မဟုတ် Microsoft Edge ဘရောက်ဆာနှင့် HTTPS လုံခြုံရေးစနစ် အောက်တွင်သာ အသုံးပြုနိုင်ပါသည်။ Firefox၊ Safari နှင့် Facebook/Messenger/Telegram in-app browser များတွင် အလုပ်မလုပ်ပါ။

လိုအပ်ချက်များ စစ်ဆေးရန် (Requirements)

  • Google Chrome သို့မဟုတ် Microsoft Edge ဘရောက်ဆာ အသုံးပြုထားခြင်း
  • ကွန်ပျူတာနှင့် ဖုန်းကို USB-C to C သို့မဟုတ် OTG ဒေတာကြိုး ဖြင့် သေချာစွာ ချိတ်ဆက်ထားခြင်း
  • ဖုန်း၏ Developer Options တွင် "USB debugging" (USB အမှားပြင်ဆင်ခြင်း) ဖွင့်ထားခြင်း
  • Xiaomi / Redmi / HyperOS ဖုန်းများအတွက် Developer Options ထဲရှိ "Install via USB" ခွင့်ပြုချက်ကို ဖွင့်ထားခြင်း
